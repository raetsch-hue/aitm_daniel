## 3. Funktionen und Anwendungsfälle – keine eigenständigen Programme

- **Gemini Gems:** individuell konfigurierte Assistenten innerhalb von Gemini
- **Deep Research:** Recherchefunktion unter anderem in ChatGPT, Gemini und Perplexity
- **Code Review:** Anwendungsfall von Codex, Claude Code und Cursor
- **Meeting-Auswertung:** Funktion unter anderem von Microsoft Copilot und Fireflies.ai
- **Bildgenerierung:** Funktion verschiedener Programme, beispielsweise ChatGPT, Gemini, Midjourney und Higgsfield AI
- **Vibecoding:** Arbeitsweise zur Softwareentwicklung mit Tools wie Lovable, Codex, Claude Code oder Cursor

## 4. Empfohlene Auswahl für den Einstieg

Um Überschneidungen zu vermeiden, bietet sich zunächst folgende Kombination an:

1. **ChatGPT oder Claude** für allgemeine Wissens- und Textarbeit
2. **NotebookLM** für die quellenbasierte Arbeit mit eigenen Dokumenten
3. **n8n oder Make** für Workflows und Systemverbindungen
4. **Power Automate oder UiPath** für RPA und operative Prozessautomatisierung
5. **Celonis** für Process Mining vor größeren Automatisierungsprojekten
6. **Codex, Claude Code oder Cursor** für Softwareentwicklung
7. **Gamma** für schnelle Präsentationen

> Nicht jedes Tool wird gleichzeitig benötigt. Die Auswahl sollte sich nach Anwendungsfall, vorhandener IT-Landschaft, Datenschutz, Integrationsmöglichkeiten und Gesamtkosten richten.
