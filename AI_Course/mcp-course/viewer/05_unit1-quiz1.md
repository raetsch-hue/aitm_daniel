# Quiz 1: MCP Fundamentals

Test your knowledge of the core concepts of Model Context Protocol.

### Q1: What is the primary purpose of Model Context Protocol (MCP)?

- **A.** To limit the training data of AI models
- **B.** To enable AI models to connect with external data sources, tools, and environments
- **C.** To replace prompting when using Large Language Models
- **D.** To create a new programming language for AI

<details><summary>Auflösung</summary><p>· A — MCP aims to expand, not limit, the contexts AI models can access.</p><p>✅ <b>B (richtig)</b> — Correct! MCP's main goal is to facilitate interoperability.</p><p>· C — MCP is a protocol that enhances prompting, not a replacement for it.</p><p>· D — MCP is a protocol, not a programming language.</p></details>


### Q2: What problem does MCP primarily aim to solve?

- **A.** The lack of AI models
- **B.** The high cost of training LLMs
- **C.** The M×N Integration Problem
- **D.** The difficulty in creating new AI algorithms

<details><summary>Auflösung</summary><p>· A — MCP addresses integration challenges, not the availability of AI models themselves.</p><p>· B — While MCP can improve efficiency, its primary focus is not on reducing training costs directly.</p><p>✅ <b>C (richtig)</b> — Correct! MCP standardizes connections to avoid M×N custom integrations.</p><p>· D — MCP facilitates using existing algorithms and tools, not creating new ones from scratch.</p></details>


### Q3: Which of the following is a key benefit of MCP?

- **A.** Reduced AI model accuracy
- **B.** Increased complexity in AI development
- **C.** Standardization and interoperability in the AI ecosystem
- **D.** Isolation of AI models from external systems

<details><summary>Auflösung</summary><p>· A — MCP aims to enhance AI capabilities, which should ideally lead to improved or maintained accuracy, not reduced.</p><p>· B — MCP aims to simplify integration, thereby reducing complexity.</p><p>✅ <b>C (richtig)</b> — Correct! This is a primary goal and benefit of MCP.</p><p>· D — MCP promotes connection and interaction, not isolation.</p></details>


### Q4: In MCP terminology, what is a "Host"?

- **A.** The external program exposing capabilities
- **B.** The user-facing AI application
- **C.** A read-only data source
- **D.** A pre-defined template for interactions

<details><summary>Auflösung</summary><p>· A — This describes an MCP Server.</p><p>✅ <b>B (richtig)</b> — Correct! The Host is the application users interact with.</p><p>· C — This describes a type of MCP Capability (Resource).</p><p>· D — This describes a type of MCP Capability (Prompt).</p></details>


### Q5: What does "M×N Integration Problem" refer to in the context of AI applications?

- **A.** The difficulty of training M models with N datasets
- **B.** The challenge of connecting M AI applications to N external tools without a standard
- **C.** The problem of managing M users across N applications
- **D.** The complexity of developing M features for N different user segments

<details><summary>Auflösung</summary><p>· A — This relates to model training, not the integration problem MCP addresses.</p><p>✅ <b>B (richtig)</b> — Correct! MCP provides the standard to solve this M*N complexity.</p><p>· C — This is a user management or identity problem, not the focus of MCP.</p><p>· D — This relates to product development strategy, not system integration in the way MCP defines.</p></details>
